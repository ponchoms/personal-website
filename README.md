# Personal Website

Alfonso "Poncho" Moreno — Academic profile site.

**Live:** https://ponchoms.github.io/personal-website/

## Stack

- Astro 5 (static)
- Tailwind CSS v4
- Bilingual: Spanish (default) / English

## Development

```bash
npm install
npm run dev
```

Opens at `http://localhost:4321/personal-website/`

## Build

```bash
npm run build
npm run preview
```
